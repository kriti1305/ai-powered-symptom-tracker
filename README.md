# AI-Powered Symptom Tracker

An interactive patient dashboard interface designed for real-time symptom intake, logging, and automated triage alert tracking.

## 🚀 Key Features Built
* **Comprehensive Frontend Panels:** Multi-page architecture including dedicated user views for `dashboard`, symptom history (`log`), and diagnostic input (`predict`).
* **AI Analysis View (`ai-analysis.html`):** Specialized interface layouts designed to display model classification metrics, severity weights, and automated health alert statuses.
* **Responsive Script Processing (`script.js`):** Engineered UI event handlers to simulate dynamic frontend validation and data parsing workflows.

## 📁 Technical Architecture
* **Interface Layer:** Structured semantic HTML5 components (`index.html`, `about.html`, etc.)
* **Presentation Layer:** Custom responsive styling sheets (`style.css`, `ai-analysis.css`)
* **Logic Simulation Layer:** Dynamic interface routing and behavioral handling (`script.js`)
